# @archstate/core

The ArchState state machine engine — config-based machines (`createMachine`), Effect Schema-validated context, and an actor model (`spawnChild`, `sendTo`, `sendParent`, `forwardTo`) built on Effect v4.

See the [repo README](https://github.com/leaderiop/archstate#readme) for the full quick start and API overview.

```bash
npm install @archstate/core effect
```

Requires `effect ^4.0.0-rc.110`.
