# @archstate/react

A typed React hook factory (`createUseMachineHook`, `createUseChildMachineHook`) for [`@archstate/core`](../core) machines, built on Effect v4's `effect/unstable/reactivity`.

See the [repo README](https://github.com/leaderiop/archstate#readme) for the full quick start and API overview.

```bash
npm install @archstate/react @archstate/core effect react
```

Requires `effect ^4.0.0-rc.110` and `react ^18 || ^19`.
